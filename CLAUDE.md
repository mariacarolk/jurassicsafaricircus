# Jurassic Safari Circus — landing page

Site estático de página única (pt-BR) para o Jurassic Safari Circus, no estacionamento do Partage Santana (Zona Norte de São Paulo).

## Estrutura
- `index.html` — página inteira (HTML + CSS inline, fontes Anton e Baloo 2 via Google Fonts).
- `assets/wallpaper.jpg` — imagem de fundo do hero.
- `assets/logo.png` — logo.
- `STORYS-CIRCO-SAFARI.jpg.jpeg` — arte de referência (stories).

## Convenções
- Sem build nem dependências: editar `index.html` direto e abrir no navegador para testar.
- Paleta em variáveis CSS no `:root` (`--dourado`, `--dourado-claro`, `--verde-escuro`, `--creme`).
- Mobile-first: a página ocupa 100dvh/100svh sem rolagem; conferir em largura de celular.
- Textos em português do Brasil.
- `*.zip` é ignorado: o pacote de upload é gerado a partir destes arquivos.
